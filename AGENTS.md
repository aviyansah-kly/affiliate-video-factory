# Agent production rules

Before changing video code, read the upstream Hyperframe Pro production skills and the official HyperFrames skills.

Required order:

```
script -> beats -> register -> generator -> lint -> check -> render -> contact sheet
```

Affiliate-specific gates:

- The first 2 seconds show the viewer's problem or a concrete result, not a generic product card.
- One hero per beat.
- Consecutive beats may not use the same framing.
- Do not invent demos, testimonials, discounts, ratings, capacity, battery life, or performance claims.
- Listing-only claims must remain attributed to the listing.
- No generated UI.
- No personal data in screenshots.
- Product identity comes from real product assets.
- Paid footage is forbidden in zero-budget mode.
- If a beat needs photoreal footage during zero-budget validation, use a deterministic fallback instead of faking proof.
